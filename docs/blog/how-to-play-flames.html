How to Play the FLAMES Game — Step by Step Guide

The FLAMES game is a classic relationship calculator that's been a favorite among friends, couples, and curious minds for decades. Here's exactly how it works.

Try the FLAMES Calculator Online →

Step 1: Enter Two Names

1

Type the first name in one field and the second name in another. You can use first names, full names, or even nicknames.

Step 2: Cancel Common Letters

2

The calculator finds letters that appear in both names and removes them. For example, if both names contain "A", one "A" from each name is crossed out.

Step 3: Count Remaining Letters

3

Add up all the letters that weren't cancelled. This count is the key to your FLAMES result!

Step 4: Eliminate Through FLAMES

4

Starting with F-L-A-M-E-S, count through the letters using your count number. Remove the letter you land on. Repeat until only one letter remains.

Step 5: Discover Your Result

5

The last letter standing is your relationship type!

  • F = Friends
  • L = Love
  • A = Affection
  • M = Marriage
  • E = Enemies
  • S = Siblings
