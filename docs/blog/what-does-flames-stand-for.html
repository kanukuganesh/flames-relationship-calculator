What Does FLAMES Stand For?

The word FLAMES is an acronym where each letter represents a type of relationship. It's the classic name game that determines your connection with someone based on your names.

The FLAMES Algorithm Explained

The game works by cancelling common letters between two names, counting the remaining letters, and using that number to eliminate letters from FLAMES in a circular pattern until one remains.

For example, if the count is 4, you count 4 letters from F: F(1), L(2), A(3), M(4) — M is eliminated. Then continue counting from the next letter until only one is left.
